# SLAP Sound System

Repozytorium z dokumentacją, plikami i narzędziami do systemu nagłośnieniowego SLAP Sound System (techno, festiwale).

## Struktura

| Folder | Zawartość |
|---|---|
| `docs/seeburg/datasheets/` | Karty katalogowe głośników Seeburg (PDF) |
| `docs/seeburg/processor/` | Biblioteka presetów procesora HDLM 8 (`PROCESSOR-SETTINGS.pdf`) z tabelą Time-Alignment |
| `docs/seeburg/time-alignment/` | Oryginalny kalkulator Time-Alignment Seeburga (xlsx) |
| `assets/seeburg/3d-models/` | Modele 3D głośników i akcesoriów (zip) |
| `assets/seeburg/photos/` | Zdjęcia produktowe (zip) |
| `apps/delay-calculator/` | Aplikacja PWA do liczenia opóźnień (gotowa do wdrożenia + źródła w `src/`) |
| `systems/` | Konfiguracja systemu: sieć Dante, racki, procesory, presety (do uzupełnienia) |
| `measurements/` | Pomiary Smaart i EASE (do uzupełnienia) |
| `projects/` | Foldery projektów i eventów (do uzupełnienia) |

## Uwagi

- Materiały Seeburg (karty, biblioteka, zdjęcia, modele 3D) należą do ich właściciela. Repozytorium ma być **prywatne**, nie publikuj go ani materiałów bez zgody producenta.
- Nazwy plików są takie jak pobrane ze strony producenta.

## Dodawanie nowych głośników

Karty PDF do `docs/seeburg/datasheets/`, zdjęcia do `assets/seeburg/photos/`, modele 3D do `assets/seeburg/3d-models/`, a dane do kalkulatora opisano w `apps/delay-calculator/README.md`.
